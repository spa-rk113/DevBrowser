🚀 DevBrowser

A lightweight Android browser with experimental developer tools.

Features

- Google Search
- Website navigation
- Back, Forward and Reload
- Inspect Element
- HTML Editor
- CSS Editor
- JavaScript Console
- Local webpage modifications

Build APK

1. Upload this project to GitHub.
2. Open the Actions tab.
3. Select Build DevBrowser APK.
4. Click Run workflow.
5. Download the DevBrowser-APK artifact after a successful build.

Requirements

- JDK 17
- Gradle 8.9
- Android SDK 35

Note

HTML and CSS changes are local to the current page. They do not modify the original website or its server.

Use the JavaScript console only on websites you trust.
